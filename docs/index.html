Method: reviews are scored with a compact TextBlob-style lexicon scorer (polarity in [-1,+1], sentiment thresholds +/-0.1). This is a simplified in-browser port for demonstration - the reference implementation is the Streamlit app in the repository, which uses real TextBlob.

Datasets: bundled default sample (41 reviews) plus three 40-row practice sets (March baseline / June improved / November incident). View the data folder.
