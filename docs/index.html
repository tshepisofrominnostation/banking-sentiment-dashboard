HOW THE SCORING WORKS
Polarity and subjectivity from TextBlob's en-sentiment lexicon (1,528 entries) plus a documented 30-term banking supplement (crash, declined, load shedding…), with negation and intensifier rules, averaged per sentence — the same approach as the Python pipeline. Labels use the identical ±0.10 thresholds, so a review lands in the same band here as it does in Python.
Known limits: sarcasm, isiZulu and code-switching are invisible to a lexicon. The parity figure above is measured against Python on this site's own corpus, not a claim about all text.
Method: polarity and subjectivity computed with TextBlob (pattern lexicon) in Python — see polish_analyze.py; results exported to docs/data.json and rendered here. Thresholds ±0.10.
Source: github.com/tshepisofrominnostation/banking-sentiment-dashboard
Limitation: TextBlob is a general-purpose English lexicon; it misses SA slang, sarcasm and isiZulu — which is why the dashboard reports scores, not verdicts.
